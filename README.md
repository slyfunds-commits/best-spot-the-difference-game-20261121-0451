Spot the Difference: The Curious Attic — two pictures hang side by side. They look the same. They are not. Find every difference before the clock runs out, across three hand-drawn rooms: the Attic (5 differences), the Garden Shed (7) and the Night Market (9). Every picture is drawn procedurally in code — no images are loaded, no network request is made. Click a difference to mark it, or move the cursor with the arrow keys and press Enter. H asks for a hint, P pauses, R restarts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `game/index.html` from any static server — the game is plain files under `game/` with no build step.
